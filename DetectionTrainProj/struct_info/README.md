# Dataset inventory snapshots

`Directory_Structure_CRDDC_RDD2022.txt` and `File_List_CRDDC_RDD2022.txt` are historical
human-readable inventories. Their paths describe the environment in which they were generated;
they are not runnable configuration, current dataset manifests or proof that listed images are
present in this checkout. Do not copy machine-specific paths from them into commands.

Use [dataset discovery and checks](../docs/DATASET.md) for the current source tree. Preserve a
new per-run input/split manifest when reproducibility is needed.

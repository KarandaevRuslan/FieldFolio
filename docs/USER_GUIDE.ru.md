# Работа с Fieldfolio

## Создание и сохранение отчёта

Откройте библиотеку и создайте отчёт. Задайте имя, при необходимости отображаемый заголовок,
описание и обложку. Добавляйте элементы в корень или во вложенные папки. Порядок элементов
определяет их положение при просмотре.

Логическое имя используется в пути ресурса. Отображаемый заголовок служит подписью на экране.
Изменение подписи не требует изменения логического имени. Соседние элементы должны иметь
уникальные допустимые имена; перенос папки внутрь самой себя не допускается.

Вложенное редактирование имеет три уровня сохранения: команда Save в Acode возвращает текст
в форму элемента, сохранение формы фиксирует элемент в черновике, сохранение отчёта записывает
его целиком. Проверьте последний шаг перед выходом. Блокировка очищает приватную сессию.

## Типы элементов

| Элемент | Использование |
|---|---|
| Папка | Группировка материалов |
| Текст и текстовый файл | Заметки, исходный код, JSON или CSS |
| Изображение | Фото и другие изображения с собственным ресурсом отчёта |
| Аудио | Запись, метаданные и обложка |
| Location | Фиксированная точка или положение устройства |
| Weather | Погода в заданной точке |
| Clock | Время в выбранном или системном часовом поясе |
| Model result | Сохранённый результат анализа с входом, рамками, масками или значениями |
| Document | Интерактивные ячейки Notebook Kit и чтение ресурсов этого отчёта |

Текст с подсветкой JavaScript остаётся текстом. Для выполнения ячеек нужен элемент Document.
Мини-просмотр Document не прокручивается; разверните его для чтения, поиска и управления.

## Карта и обновление данных

Точка наблюдения и камера карты — разные состояния. Масштабирование карты не должно менять
координаты элемента. При отсутствии разрешения на геолокацию можно продолжить работу с
ручными координатами и обычными материалами.

Погодные карточки используют общий координатор и кэш. Ошибка обновления не должна стирать
предыдущее значение. Clock с источником устройства использует системный часовой пояс и сам
по себе не требует GPS.

## Анализ

Выберите локальную модель или серверный адаптер и соответствующий вход. Настройки локальной
модели должны соответствовать форме и типу её тензоров. Серверный анализ требует доступного
backend и настроенной учётной записи. Результат можно включить в отчёт как отдельный элемент.

Рамки и полигоны относятся к сохранённому входу анализа. После кадрирования не накладывайте
их на другое исходное изображение без преобразования координат. Снимок результата остаётся
доступен независимо от дальнейшего удаления модели из каталога.

## Обмен и защита

Библиотечный экспорт переносит выбранные папки и отчёты с ресурсами. Для полного переноса
закрытых материалов учитывайте пароль и состояние доступа. Проверяйте набор восстановленных
вложений после импорта.

Экспорт выделенных элементов и отдельного результата анализа создаёт открытый ZIP-снимок.
Он не наследует автоматически пароль защищённого отчёта. Скрытие элемента или его заголовка
управляет отображением; оно не запрещает чтение другими Document в том же открытом отчёте.

[Справочник Document на русском](../MobileApp/docs/api/document-ru.md) описывает VFS, ячейки,
таймеры, медиа и ограничения среды исполнения.

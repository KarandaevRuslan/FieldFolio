# README entry points

The repository README already links to [the documentation index](README.md).
The two product entry points are [README.md](../README.md) and [README.ru.md](../README.ru.md).

When adding a component guide, link it from `docs/README.md` and the component README.
Use paths relative to the containing file. Do not copy installation instructions into a
second README when a link to the maintained guide is sufficient.

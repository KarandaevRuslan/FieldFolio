# Координаты, погода и обновление контекста

`ResourceCoordinator` в `core/datarefresh/` принадлежит приложению. Он объединяет запросы
координат и погоды, хранит последние показания и обслуживает активные подписки интерфейса.
Уход карточки из списка освобождает подписку, но не отменяет уже начатый общий запрос.

## Периодичность

| Источник | Автоматическое обновление | Ручное обновление |
|---|---|---|
| Геолокация устройства | Общий цикл с шагом 30 с при наличии потребителей | Запрос свежего fix; одновременные вызовы объединяются, после завершения пауза 2 с |
| Погода в заданной точке | Проверка после 350 мс при появлении и затем раз в минуту; свежесть 20 мин, повтор после ошибки через 60 с | Общий запрос для точки; пауза 10 с после завершения |
| Погода у устройства | Общая геолокация; погодная точка меняется при смещении не менее 1 км | Сначала координаты, затем погода для выбранной точки |
| Часовой пояс устройства | Системные события и возврат на экран | GPS и погодный HTTP не требуются |

Погодные запросы выполняются с параллелизмом до трёх. Перед началом HTTP из очереди убирается
автоматический запрос, если у него больше нет подписчиков. Освобождение подписок имеет задержку
7 с; кеш хранится отдельно. Ошибка обновления не удаляет последнее успешное показание: интерфейс
отображает ошибку и признак устаревания. Время старого GPS-fix при чтении кеша не заменяется текущим.

## Интерфейс и карты

UI регистрирует потребности через `rememberDeviceFix`, `rememberWeatherReading`,
`RegisterDeviceWeatherRefresh` и `OsmFocusPointFeed`. `RefreshScope` объединяет ресурсы
просмотрщика/Preview для Pull to Refresh. Жесты карты остаются у OSMDroid; полноэкранная карта
использует общий polling. Разрешение на геолокацию повторно проверяется после callback и при
возврате на экран; активный потребитель может запросить координаты после выдачи разрешения.

Точки карты различаются по ID. Разные участники на одинаковых координатах сохраняются.
`Focus target` переводит камеру к цели; дубликат уже имеющейся цели в меню не добавляется.
Пункты сортируются по расстоянию от origin. Настройка **Show current map center** управляет
строкой центра карты в меню, а не камерой, GPS или маркерами. `deviceLocation` у Clock означает
системный часовой пояс Android.

## Document и VFS

Чтение `Folio.vfs.get(...)` получает снимок через `DocumentAccessContext`; само чтение не
запрашивает разрешений, GPS или внешней сети. Активный нативный Document Runtime подписывает
нужные ресурсы отчёта, включая скрытые Location/Weather с `deviceLocation`, чтобы последующие
чтения могли получить обновлённые данные. JavaScript не управляет провайдером напрямую.
Справка не получает погодный провайдер, а публичного `Folio.watch(...)` нет.

Проверяйте общий запрос при многократном обновлении, уход/возврат карточки, очередь без
подписчиков, отказ/выдачу разрешения, последовательность GPS→погода и блокировку отчёта.
Команды и границы проверок описаны в [TESTING.md](TESTING.md).
